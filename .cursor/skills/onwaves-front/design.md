# Дизайн OnWaves

Дизайнер агрегаторов и маркетплейсов: экран красивый, живой, и с него сразу хочется записаться / купить. Не «аккуратная админка» и не «сайт агентства».

## Токены (`src/assets/styles/main/color.scss`)

| Роль | Значение |
|------|----------|
| Тёмный бренд / H1 | `$green-dark: #043c48` |
| Основной | `$green-basic: #006174` |
| Акцент / градиент CTA | `$green-light: #0d94a0` → `$green-basic` |
| Тема PWA | `#1f8f8f` |
| Текст | `$black: #23262F` / на лендингах часто `#11142d` |
| Фон страницы | `$grey-light: #FAFAFC` |
| Успех / ошибка | `#4FB229` / `#d46c54` |

Шрифт: **Montserrat** (woff2 + woff, `font-display: swap`). Не подключай второй display-шрифт на витрину.

Кнопки продающих экранов: высота 56px, `border-radius: 999px`, primary — градиент + тень `rgba(13, 148, 160, .28)`. Ghost — белый фон, обводка `rgba(4, 60, 72, .14)`. На тёмной секции обе CTA белые, различие — иконка канала (MAX / Telegram), не цвет заливки.

## Брейкпоинты (практика репо)

Единого mixins нет — ориентир:

| Ширина | Смысл |
|--------|--------|
| ≤480 | мелкий телефон, табы/карточки в одну колонку |
| ≤640 | основная мобила (воронка записи, услуги) |
| ≤768 | планшет / узкий десктоп, колонка профиля |
| ≤980 | лендинг `/masters` складывает hero |
| 1200 | `.disp1` — ширина контента |

Пиши mobile-first: базовая колонка, затем `@media (min-width: 768px)` или зеркально `max-width` как у соседнего файла. Не копируй пять промежуточных точек без нужды.

## Сетка и ритм

- Контентная колонка ≤1200px, горизонтальные поля мобилы 16–20px.
- Вертикальный ритм секций лендинга 48–64px, внутри карточки 16–24px.
- Карточки: скругление 16–24px, лёгкая тень, без непрозрачного чёрного.
- Иконки категорий — линейные, в одном весе; не смешивай filled и outline в одном ряду.

## Витрина маркетплейса (хочется купить)

Карточка услуги / мастера / слота — товар, не строка списка.

- Крупное фото или аватар, затем имя, цена, длительность, слот, CTA. Рейтинг и район — вторичны.
- Цена и кнопка читаются сразу, не серым 12px. На карточке один явный action.
- Воздух важнее рамок: лучше больше padding и одно сильное фото, чем сетка из восьми мелких плиток.
- Состояния «живости»: сегодня свободно, ближайший слот, «записываются». Пустое фото не маскируй плейсхолдером-логотипом как будто это контент.

## Motion

Динамика продаёт, если не орёт.

- Появление секций: `opacity` + лёгкий `translateY(8–12px)`, 200–320ms, `ease-out`. Только `transform`/`opacity`.
- Карточка: лёгкий lift/тень на hover (десктоп) и `scale(0.98)` на `:active` (палец). CTA — press-state обязателен.
- Не используй infinite-loop, bounce и параллакс на витрине. Не анимируй layout (`top`/`height`) — дёргает SSR и слабые телефоны.
- Respect `prefers-reduced-motion: reduce`.

## Продающая упаковка (чеклист)

1. Первый экран: оффер + подзаголовок + CTA. Без карусели из пяти равнозначных кнопок. На 390 платной посадки (`/cellings`) обложка не выталкивает CTA ниже сгиба.
2. Выгода списком из 3–4 пунктов, не абзацами.
3. Доказательство: цифра, кейс, ссылка на живой профиль.
4. Финальный блок: повтор CTA + мессенджеры. Клик по MAX/Telegram на `/masters` ещё зовёт `sendLandingEvent`.
5. Пустое состояние и ошибка — человеческий текст, не «Error 500».
6. Тест на себя: открыл мобилу 390px — через 3 секунды понятно, что брать, и рука тянется к кнопке.

## Анти-паттерны

- Разный зелёный в одном экране (PrimeNG saga-blue vs бренд) — перекрась контрол токенами.
- Мелкий серый текст CTA на сером фоне.
- Десктоп-меню, которое на 390px вылезает за край.
- Фиксированный `width: 1200px` без `max-width: 100%`.
- `overflow: hidden` на теле страницы, обрезающий клавиатуру iOS в формах записи.
- Таблица вместо витрины: услуга без фото, цена в уголке, CTA спрятан.
- «Красиво, но холодно»: много воздуха и нет причины нажать.
- Анимация ради анимации: крутящиеся иконки, карусель из пяти равнозначных CTA.
