# Ветки OnWaves Front

Новые изменения и коммиты идут в `dev`. Перед выпуском проверьте выбранные коммиты на тестовом стенде и соберите согласованные browser и SSR. В `production` фиксируйте Git SHA того снимка, из которого выложена рабочая версия. Записывайте SHA рядом с хешами сборок в журнале выпуска.

Проверяйте назначение remote и триггеры перед отправкой веток. Отправка в Git и ручная выкладка — отдельные действия. Повседневная рабочая ветка — `dev`. Локальные конфиги, результаты сборок и материалы QA хранятся отдельно от истории.
