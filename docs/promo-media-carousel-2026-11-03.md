# Карусель фото и видео акции

Сделано 03.11.2026 по запросу оформления акций Натальи Макаровой.

## Поведение

У акции с несколькими медиа обложка и дополнительные материалы отображаются одной каруселью. Фото переключаются автоматически каждые 6 секунд. Есть стрелки, индикаторы с выбором кадра, свайп изображения, клавиатурные стрелки и кнопка остановки автопрокрутки. Кадр показывается целиком; фон — размытая копия того же изображения.

Автоматическое переключение приостанавливается при наведении мыши, фокусе внутри карусели, воспроизведении видео, скрытии вкладки и выходе блока за пределы видимой области. При `prefers-reduced-motion: reduce` автоматическая смена выключена, ручное управление доступно. Видео запускается только посетителем. Переход на другой слайд уничтожает экземпляр плеера и останавливает прежний ролик.

Битое изображение или недоступное видео удаляется из текущего набора. При одном оставшемся материале управление скрыто. При обновлении самой акции набор сбрасывается на первый кадр; повторная передача неизменного списка не сбрасывает просмотр.

## Подключение

- Новый компонент: `src/app/profile-ba/components/promo-media-carousel/`.
- Объявлен в `LandingUiModule` и используется `LandingOfferCardComponent`.
- Данные берутся из существующих `coverMedia()` и `extraMedia()`: `offer.imageUrl`, `offer.media`, совместимость с `offer.galleryUrls` сохранена. Новые API и поля контракта не нужны.
- Одно изображение использует прежнюю вёрстку. Рекламный `cellingsHero` сохраняет прежние обложку и порядок оффера/CTA.
- Событие запуска видео передаётся через существующий `videoStart`; дополнительных целей или хитов нет.
- Условия акций, расчёт цен, услуги и запись не менялись.
