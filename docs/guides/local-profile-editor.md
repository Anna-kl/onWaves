# Заполнение существующего профиля через localhost

Указание Анны от 03.11.2026. Применять при поручении заполнить уже существующий профиль мастера.

## Вход

1. Открыть `http://localhost:4200` в разрешённом браузере. Проверить, кто уже вошёл: аккаунт другого мастера не использовать для изменений.
2. Для переключения аккаунта выйти через меню сайта и нажать «Вход».
3. Ввести телефон мастера из подтверждённого пакета материалов. В форме с отдельно показанным `+7` вводятся следующие 10 цифр, без повторного `7`.
4. На шаге подтверждения в текущем локальном окружении использовать тестовый код `1111` — по явному указанию Анны. Проверено 03.11.2026: локальная проверка приняла этот код. Правило не переносится на `onwaves.online`, другие окружения или чужие аккаунты.
5. После входа проверить имя и доступный бизнес-профиль. Редактор: `/ba-edit/{businessProfileGuid}/uslugi`; публичный URL использует slug, а не GUID. Проверить совпадение ID с заданием до первого сохранения.

**Если появляется «Представьтесь, пожалуйста», не заполнять имя и не нажимать «Далее» ради получения доступа.** Эта ветка открывается, когда после проверки кода сервер не вернул `profileUserId` (`modal-enter-data.component.ts`, метод `next`). Продолжение создаёт новый UA-профиль (`modal-register-next.component.ts`, метод `next`), а не выбирает существующий. Уточнить номер или штатную привязку существующего аккаунта; не менять владельца и не создавать дубликат демо-страницы.

## Сохранение и проверка

- Перед изменениями сохранить актуальные поля, serviceId, изображения и снимки. Октябрьский пакет или старый локальный HTML не заменяет свежий снимок.
- Менять поля через штатный редактор. Сохранять serviceId услуг с неизменным смыслом; старые пакеты скрывать с сохранением истории, а не переиспользовать для других услуг.
- Длительность и расписание брать из подтверждённых данных. Если редактор требует неизвестное значение, не вводить заглушку для прохождения формы.
- Для несогласованной страницы оставить деморежим включённым и приём заказов выключенным (`isPromo=true`, `isGetOrder=false`); акции не включать без отдельного согласования.
- После сохранения перечитать данные и проверить публичный профиль на 390 / 768 / 1280 px. Отдельно проверить `https://onwaves.online/{slug}`: localhost сам по себе не доказывает обновление боевого сайта, даже если локальный API использует общую БД.
- В отчёте отличать статический локальный проект, сохранённые локальные данные и проверенное обновление существующей демо на сайте. Реальные OTP, JWT и cookies не сохранять в отчёты и снимки. `1111` в этом документе — указанная владельцем константа локального тестового входа.
